# Functional User stories

## US1: view Katalog
As a user, 
I want to access the website and see the Katalog
so that I can look at the available books. 

## US2: add books to Mina böcker
As a user, 
I want to add books in "Mina böcker",
so that I can keep track of my favourite books. 

## US3: remove books from Mina böcker
As a user,
I want to remove books from "Mina böcker", 
so that I can manage my favourites. 

## US4: add new books to Katalog
As a user, 
I want to add new books on Katalog using "Lägg till bok" by entering the required information,
so that newly added books appear in the Katalog.

## US5: view statistics
As a user, 
I want to see the Statistik showing total number of books and favourites, 
so that I can keep track of my favourites and Katalog.
